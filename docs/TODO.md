### HABILIDADES A APLICAR

### REGLAS DE EJECUCIÓN

1. **Fase 1: Extracción de Contenido (Preserve Content, Scrap Design)**
   - Extraé todo el texto, jerarquía de información, formularios, enlaces y valor funcional del HTML adjunto.

2. **Fase 2: Aplicación de `desinf-taste-frontend` (Anti-AI Slop Checklist)**
   - Evitá diseños genéricos de plantilla ("AI Slop"). No utilices layouts centrados aburridos ni gradientes purpúreos/azulados trillados sobre fondo negro absoluto.
   - Usá espaciados asimétricos deliberados, tipografía con personalidad técnica (p. ej. `Geist`, `Inter`, `JetBrains Mono` para detalles) y escalas contrastantes.
   - Aplicá una paleta de colores calculada en espacio perceptual (`oklch`) con tonos oscuros profundos, bordes sutiles semi-transparentes y un único color de acento de alto impacto.

3. **Fase 3: Aplicación de `web-design-engineer` (Estética Tech / Modern SaaS)**
   - **Layout:** Reorganizá la información utilizando estructuras modernas tipo *Bento Grid*, cards modulares con bordes `border-white/10` y micro-detalles visuales.
   - **Interacción:** Sugerí o implementá estados hover pulidos, transiciones suaves y micro-interacciones (usando Tailwind CSS o CSS puro).
   - **Componentes:** Maquetá componentes sobrios, limpios y densos en información (estética tipo Vercel / Linear / Raycast).

### OUTPUT REQUERIDO
Generá la nueva versión completa en HTML5 semántico + Tailwind CSS (o CSS moderno autocontenido). El código debe ser listo para producción, responsivo y sin omitir ninguna sección del contenido original.
